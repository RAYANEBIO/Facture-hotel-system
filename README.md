# 🏨 Facture Hotel System

## 📌 Description
Facture Hotel System est une application permettant de gérer la facturation dans un hôtel.  
Elle facilite le suivi des clients, des réservations et des paiements, tout en automatisant la génération des factures.

---

## 🚀 Fonctionnalités
- Gestion des clients (ajout, modification, suppression).  
- Gestion des réservations et séjours.  
- Génération automatique des factures.  
- Suivi des paiements et des encaissements.  
- Interface simple pour le personnel hôtelier.  

---

## 🛠️ Technologies utilisées
- **Langage** : Java (ou C/C++ si ton projet est mixte).  
- **Base de données** : MySQL / SQLite (à préciser selon ton code).  
- **Outils** : Git, GitHub, IDE (Eclipse, IntelliJ, ou autre).  

---

## 📂 Installation et utilisation
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/RAYANEBIO/Facture-hotel-system.git
   ```
2. Ouvrir le projet dans ton IDE préféré.  
3. Configurer la base de données (script SQL fourni si disponible).  
4. Compiler et exécuter le projet :
   ```bash
   javac Main.java
   java Main
   ```
   *(ou exécuter directement depuis l’IDE)*
